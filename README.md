# Yacine TV Web — التشغيل الكامل

## البنية
- `index.html` — واجهة الويب (تصنيفات/قنوات/مباريات/بحث/مشغل hls.js)
- `app.js` — السيرفر الرئيسي على المنفذ **8891**:
  - `/api/*` → يجلب من `https://def55.ycnapi.com/api/*` (الـ API الحقيقي، يأتي من Firebase Remote Config) ويفك تشفير الردود
  - `/media?url=...&ua=...&headers=...` → بروكسي وسائط يمرر الـ headers/user-agent الحقيقية ويعيد كتابة روابط m3u8
- `proxy.js` — بروكسي تسجيل مرور منفصل على 8890 (اختياري، لالتقاط الروابط)

## لماذا يحتاج سيرفر؟
- الـ API يتطلب `User-Agent: okhttp` (Cloudflare يرفض غيره) — المتصفحات لا تستطيع إرساله
- ردود الـ API مشفرة — **فك التشفير صار داخل `app.js` بـ JavaScript خالص** (XOR keystream = SALT16 + مفتاح=T header) — **لا يحتاج جوال إطلاقاً**
- الروابط تحتاج Referer مخصصاً برموز غير مرئية — المستحيل من المتصفح
- لذلك `app.js` لازم يعمل على أي جهاز يشغّل Node.js — كمبيوتر، أو **Termux على الجوال**، أو استضافة مجانية

## التشغيل
لا يحتاج جوال — يكفي Node.js:
```
node app.js
```
ثم افتح http://localhost:8891 (أو http://<IP-الجهاز>:8891 من أجهزة أخرى على نفس الشبكة)

ملاحظة: `start.bat` ما زال يدعم وضع الجوال كاحتياط لكن لم يعد ضرورياً.

## ملاحظات
- الـ API host قد يتغير — يُجلب من Firebase Remote Config (project `ycntv-7a08e`). إن تعطل، حدّث `API_HOST` في app.js.
- بعض القنوات url_type=4 (يوتيوب) و5 (مشغل ويب) تُعالج في الواجهة.
